# VivaMente

Repositorio integrado do VivaMente. Cada aplicacao mantem suas dependencias e comandos de execucao.

Os workflows de testes de Back, Oauth, Loja e Plataforma ficam em `.github/workflows/`. Os comandos de cada aplicacao continuam sendo executados a partir de sua propria pasta. Integracoes externas de deploy devem apontar para a pasta da aplicacao dentro deste repositorio.
